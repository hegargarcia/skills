## Personal Preferences

Before making subjective choices or creating or modifying an artifact, read and apply the global `personal-preferences` skill (source: ~/dev/skills/skills/personal-preferences/SKILL.md).

This is an internal guardrail, not a user-facing workflow. Treat the guide as constant — apply it, don't edit it. Feedback is folded in by a weekly review; edit the tracked source only when Hegar explicitly asks to record something now.

## Workflows

- Building, changing, or fixing product code — including feature kickoffs that arrive as proposals, scoping, or "we're missing X": follow the `showrunner` skill (~/dev/skills/skills/showrunner/SKILL.md).
- Multi-step work gets a plan per the `html-plan` skill (~/dev/skills/skills/html-plan/SKILL.md); plans live at ~/.plans/<project>/<slug>/plan.html and are never committed.
